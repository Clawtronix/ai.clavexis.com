Get ClavexisAI

The whole app runs on your own computer — its backend and interface both. Download it, then activate it with the licence key from your monthly or lifetime licence.

What you need

  • System: Windows 10 or 11 (64-bit), macOS 12 or newer, or a recent 64-bit Linux.
  • Memory: 8 GB works with the small local models; 16 GB is comfortable. No graphics card needed.
  • Disk: about 2 GB for the app, plus 2–10 GB for the local models you choose (chat model about 2 GB, photo reader 0.6 GB, “Look closer” 3.3 GB, local picture maker 2.5 GB).
  • Local AI: the free Ollama app — ClavexisAI walks you through it. Or skip it and use your own cloud AI key.
  • Internet: only to download, activate, and for web research, email, calendars or cloud models.
⊞

Windows

Windows 10 or 11, 64-bit
Download installer for Windows
  1. Run ClavexisAI-…-windows-setup.exe. If Windows shows “Windows protected your PC”, click More info → Run anyway (the installer isn't code-signed yet).
  2. Click Next → Install. No Python or administrator password needed.
  3. ClavexisAI opens straight away, with nothing extra to download — create your account; the first account on a computer is its owner.
Download for Windows
  1. Install Python 3.12 from python.org — tick “Add python.exe to PATH” on the first screen.
  2. Unzip the download, e.g. to Documents\ClavexisAI.
  3. Double-click ClavexisAI.bat. The first start installs what it needs (about 5–10 minutes) and adds a ClavexisAI shortcut to your Desktop and Start menu — use that from then on; it opens in seconds.
  4. Create your account in the window that opens — the first account on a computer is its owner.
⌘

macOS

macOS 12 or newer, Apple silicon or Intel
Download for macOS
  1. Install Python 3.12 from python.org (or brew install python@3.12).
  2. Open Terminal in your Downloads folder and unpack it: tar -xzf ClavexisAI-*-macos.tar.gz && cd ClavexisAI
  3. Start it: ./clavexisai.sh The first start installs what it needs (5–10 minutes).
  4. Optional: ./clavexisai.sh --install adds ClavexisAI to your Applications folder.
🐧

Linux

Ubuntu 22.04+, Debian 12+, Fedora 39+ (x86-64)
Download for Linux
  1. Install Python and its virtual-env module: sudo apt install python3 python3-venv python3-pip (Fedora: sudo dnf install python3 python3-pip)
  2. Unpack and start: tar -xzf ClavexisAI-*-linux.tar.gz && cd ClavexisAI ./clavexisai.sh
  3. Optional: ./clavexisai.sh --install adds it to your applications menu.
ClavexisAI needs a licence key: buy one, then open ClavexisAI, paste the key when it asks and press Activate. Your key is in your account and in the email we send.

Free, private AI on your own computer (recommended)

ClavexisAI works with no API key by running an AI model on your computer through Ollama. Nothing you type leaves it.

  1. Install Ollama from ollama.com/download.
  2. Download the fast everyday model (about 2 GB): ollama pull llama3.2:3b
  3. Optional, for harder tasks if you have 16 GB of memory (about 4.7 GB): ollama pull qwen2.5:7b
  4. That's it — ClavexisAI starts Ollama by itself and picks the right model for each job.

Recommended computer: 16 GB of memory and 10 GB free disk. 8 GB works with the small model.

ClavexisAI browser extension

Your assistant beside every web page — summarize pages, ask about what you're reading, and right-click any text to explain, translate, improve it or save it to ClavexisAI. Works with Chrome, Edge, Brave and Opera.

Download extension
  1. Download and unzip the extension to a folder you'll keep (e.g. Documents\ClavexisAI-extension).
  2. Open chrome://extensions — in Edge edge://extensions — and switch on Developer mode.
  3. Click Load unpacked and choose the unzipped folder.
  4. Start the ClavexisAI app, then sign in on the page the extension opens (same username and password as the app).
  5. Pin the ClavexisAI icon. Shortcuts: Alt+Shift+C opens it, Alt+Shift+S summarizes the page.
